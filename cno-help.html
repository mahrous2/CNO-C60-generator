🔬 CNO Generator - User Guide

What is a Carbon Nano-Onion (CNO)?

Carbon nano-onions are multi-shell fullerene structures composed of concentric carbon spheres. Each shell is a fullerene cage (like C60, C240, C540) nested inside one another, resembling the layers of an onion.

This tool generates these structures using Goldberg-Coxeter (GC) construction with optional Fibonacci-guided bond optimization for improved geometric quality.

Shell Orders (n values)

Format: Comma-separated integers (e.g., 1,2,3)

Each "n" value defines a fullerene shell using the formula: 60 × n² atoms

  • n=1 → C60 (buckminsterfullerene, 60 atoms)
  • n=2 → C240 (240 atoms)
  • n=3 → C540 (540 atoms)
  • n=4 → C960 (960 atoms)
Enter "1,2,3" to create a 3-shell onion with C60 (innermost), C240 (middle), and C540 (outermost)
Use only positive integers. No duplicates allowed. Larger n values create bigger shells.

Mode

Goldberg-Coxeter (n,0): Standard icosahedral fullerene construction with systematic vertex placement.

GC + Fibonacci Bonds: Enhanced version that uses Fibonacci sphere distribution to guide bond formation, resulting in more uniform bond lengths and improved structural quality.

For research-quality structures, use "GC + Fibonacci Bonds" mode. It produces more realistic geometries.

Random Seed (optional)

Format: Integer (e.g., 42, 12345)

Seeds the random number generator for reproducible results. If you use the same seed with identical parameters, you'll get the exact same structure every time.

Leave blank for random generation, or enter "42" to ensure reproducibility

Vacuum Padding (Å)

Format: Number ≥ 0 (e.g., 10.0)

Adds extra empty space around the structure in exported files. This is important for periodic boundary condition simulations to prevent unwanted interactions between periodic images.

Use 10-15 Å for typical MD simulations to ensure shells don't interact with their periodic images

Bond Scale

Format: Number > 0 (typical: 0.8 - 1.2)

Adjusts the strength of bond regularization during structure optimization. Higher values encourage bonds closer to the ideal carbon-carbon distance (~1.42 Å).

  • 1.00: Standard (recommended for most cases)
  • 0.80-0.95: Softer constraints, more flexible geometry
  • 1.05-1.20: Stricter constraints, more uniform bonds

Reference Shell File (optional)

Format: Plain text file with lines: C x y z

Upload a reference structure (e.g., from a previous simulation or DFT calculation) to automatically fit the α (alpha) parameter. The tool will analyze the reference and scale your generated shells accordingly.

Example file content:
C 0.000000 0.000000 1.420000
C 1.229321 0.000000 0.710000
C 0.614661 1.064638 0.710000
When using a reference, you must also specify which shell it represents using "Reference Shell n_ref"

Reference Shell n_ref (optional)

Format: Integer matching one of your shell orders

Specifies which shell your reference file corresponds to. For example, if you upload a C240 reference structure, set n_ref = 2.

The tool will measure the radius of your reference and use it to calibrate the α parameter for all shells.

Alpha (Å)

Format: Number > 0 (typical: 3.4 - 3.7)

The scaling factor that determines shell radii. Each shell's radius ≈ α × n.

  • 3.54 Å: Typical default (recommended starting point)
  • 3.45 Å: Tighter shells, more compact
  • 3.65 Å: Looser shells, more space between layers
If you upload a reference file, you can leave α blank - it will be auto-calculated from your reference structure.

Output Prefix

Format: Text (e.g., onion_60_240_540)

Sets the base filename for all exported files. If you enter "my_cno", you'll get:

  • my_cno.xyz - XYZ coordinate file
  • my_cno.cif - Crystallographic Information File
  • my_cno.data - LAMMPS data file
  • in.my_cno - LAMMPS input script

Visualization Controls

Show bonds: Toggle visibility of chemical bonds between carbon atoms

Show axes: Display X/Y/Z coordinate axes for orientation

Shell view dropdown: Filter to view specific shells or all shells together

Mouse controls:

  • Drag: Rotate the structure
  • Scroll: Zoom in/out
  • Legend click: Quickly filter to a specific shell

Bond-Length Histogram & NN Inspector

Analyzes the distribution of bond distances in your structure:

  • 1st NN: Nearest neighbor (direct bonds, should be ~1.42 Å for sp² carbon)
  • 2nd NN: Second-nearest neighbors (across hexagons)
  • 3rd NN: Third-nearest neighbors (further connections)

The histogram shows distribution, while the inspector displays min/mean/max values. Use this to assess structural quality - tighter distributions indicate more uniform geometry.

Export Formats

XYZ: Simple Cartesian coordinate format, readable by most molecular visualization tools (VMD, Avogadro, etc.)

CIF: Crystallographic Information File, standard format for crystallography and materials databases

LAMMPS: Exports both a data file and input script ready for molecular dynamics simulations with LAMMPS software

Quick Start Guide

  1. Enter shell orders (e.g., 1,2,3)
  2. Choose mode (GC + Fibonacci Bonds recommended)
  3. Set Alpha to 3.54 (or leave blank if using reference)
  4. Optionally set Vacuum Padding to 10
  5. Click Generate
  6. Explore the 3D visualization and bond analysis
  7. Download your preferred format (XYZ/CIF/LAMMPS)
